# E-Commerce Website Automation Testing

## Project Overview
This project performs automated functional testing of the Demoblaze e-commerce website using Python and Selenium WebDriver.

## Technologies Used
- Python 3.13.1
- Selenium WebDriver
- Pytest
- Pytest HTML
- Google Chrome

## Test Cases
1. Homepage loading
2. Login form verification
3. Product listing verification
4. Add product to cart
5. Remove product from cart
6. Checkout process

## How to Run

Install dependencies:

`pip install -r requirements.txt`

Execute tests:

`python -m pytest -v -s`

Generate HTML report:

`python -m pytest -v --html=reports/report.html --self-contained-html`
